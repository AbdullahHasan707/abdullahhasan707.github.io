FlyRank Search Intelligence & Content Refresh

Machine Learning / Search Intelligence

A machine learning project developed during the FlyRank ML Internship to analyze content performance and identify pages that may benefit from content refresh actions.

Problem

Websites can contain many pages with different levels of search performance. The goal of this project was to use available page-level data to identify declining or underperforming content and prioritize pages for potential refresh.

Approach

I explored and prepared an anonymized dataset containing approximately 30,000 pages. I performed data discovery, feature preparation, baseline rule creation, and machine learning model training.

Machine Learning

  • Logistic Regression
  • Decision Tree
  • Random Forest

Key Work

  • Explored page-level search and engagement data
  • Prepared features for machine learning
  • Created a baseline content-refresh rule
  • Trained and compared multiple ML models
  • Used a client holdout strategy for evaluation
  • Generated predictions and model results

Best Model

Random Forest performed best among the tested models and was selected for the final prediction workflow.

What I Learned

This project helped me understand how machine learning can support search intelligence workflows, including feature engineering, baseline comparison, model evaluation, and prioritization of content for potential refresh.
