## Portfolio Q&A Agent

An AI agent embedded on this site that answers questions about my projects, skills, and experience.

### What it does
Visitors can ask questions such as:
- What projects has Abdullah worked on?
- Tell me about his FlyRank internship
- What skills does he have?
- Summarize his experience

### How it works
- Built with **Chatbase** (free plan)
- Knowledge base: Resume + project descriptions + portfolio content
- Embedded directly on the GitHub Pages site

### How to use
1. Open the live site
2. Click the chat bubble (bottom right)
3. Ask any question about my work

### Limitations
- Only answers based on the uploaded documents
- Cannot invent new projects or experience
- Best with clear, specific questions

### Built with AI
I used AI tools (Claude + Chatbase) to design, write instructions, and test the agent. I reviewed and verified all answers myself.
